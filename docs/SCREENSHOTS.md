# Screenshots for the README

The README has a hidden slot for each screenshot below, so the page doesn't show broken images. To add one:

1. Save the image in `docs/images/` with the file name shown.
2. In `README.md`, find the matching `<!-- SCREENSHOT: ... -->` block and delete the comment lines around the `![...](...)` line, so only the image line is left.

| File | What to capture | Tip |
| --- | --- | --- |
| `hero.png` | The main menu as seen in the headset, with the UI panel and cursor visible | Take it from the SteamVR "VR View" window, or the game window, after the fix is working |
| `before-after.png` | The same menu with UUVR alone (ghosting or black screen) and with the plugin | Put them side by side in one image |
| `raipal-1-search.png` | Rai Pal's **Games** tab with `Void Crew` typed in the **Search...** box | Crop to the Rai Pal window |
| `raipal-2-install-uuvr.png` | Void Crew's page in Rai Pal, showing **UUVR Mono Modern** and its **Install** button | Before installing, so the Install button is visible |
| `raipal-3-open-mod-folder.png` | The **⋮** menu on the **BepInEx** row, open, showing **Open Mod Folder** | |
| `vr-settings-tab.png` | The game's Settings menu with the **VR** tab selected | Take it on the desktop or in VR View |
| `plugins-folder.png` | File Explorer showing `BepInEx\plugins` with `uuvr-mono-modern` and `VoidCrewVRUIFix.dll` | Hide or blur your Windows user name if it shows in the address bar |

Keep images under about 1 MB each (PNG, or JPG for photos of the headset view) so the page loads quickly.
